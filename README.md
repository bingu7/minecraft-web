# ⛏️ 我的世界 - 网页版

一个用原生 WebGL 构建的 Minecraft 风格体素沙盒游戏，**零外部依赖**，纯 HTML + JavaScript。

## ✨ 特性

- 🌍 **程序化地形生成** — 基于 Perlin/FBM 噪声生成起伏的山丘、沙滩、水域
- 🎨 **18 种方块** — 草、泥、石、沙、木、树叶、木板、鹅卵石、玻璃、砖、水、基岩、煤矿石、铁矿石、金矿石、钻石矿、雪、沙砾
- 🌅 **昼夜循环** — 300 秒一天，含日落/日出道色
- 🌫️ **雾效** — 远景渐变融合到天空色
- 💧 **半透明水渲染** — 独立 mesh + 深度写入禁用 + specular 高光
- ⚡ **DDA 射线检测** — 可靠的方块选中/放置算法
- 🎮 **第一人称控制** — 鼠标视角 + WASD 移动 + 物理碰撞
- ✈️ **飞行模式** — 按 F 切换，空格上升 Shift 下降
- 🔨 **方块交互** — 左键破坏（0.35 秒），右键放置，1-9 切换物品
- 🌳 **三种树种** — 橡树（矮冠）、白桦（高瘦）、松树（层叠锥形）
- 🕳️ **矿洞系统** — 3D 噪声在 y<20 生成洞穴
- ☁️ **云朵层** — 程序化噪声云纹理在天空 y=48 处
- 🌑 **深度暗化** — 地下/水下逐渐变暗模拟光照衰减
- 🎯 **方块选中高亮** — TRIANGLES 边框面板（替代 LINES 兼容性更好）
- 🧱 **FBM 纹理** — 3 层噪声叠加生成更丰富表面
- 👤 **第三人称视角** — 按 V 切换，蓝色方块人模型
- 🖱️ **鼠标灵敏度可调** — `[` 降 `]` 升

## 🎮 操作

| 按键 | 功能 |
|------|------|
| **W A S D** | 移动 |
| **空格** | 跳跃 / 飞行模式上升 |
| **左 Shift** | 蹲下 / 飞行模式下降 |
| **F** | 切换飞行模式 |
| **V** | 切换第一/第三人称视角 |
| **[`** / **`]** | 鼠标灵敏度降/升 |
| **鼠标移动** | 转视角 |
| **鼠标左键** | 破坏方块 |
| **鼠标右键** | 放置方块 |
| **1 - 9** | 切换物品栏 |
| **滚轮** | 切换物品栏 |
| **ESC** | 暂停 |

## 🚀 运行

```bash
cd minecraft-clone
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 🛠️ 技术栈

- **渲染**：原生 WebGL 1.0（无 Three.js 等库）
- **着色器**：GLSL 顶点 + 片段着色器
- **物理**：自实现 AABB 碰撞 + 重力 + 摔伤
- **世界**：16×64×16 区块，渲染距离 5 区块（11×11 = 121 个区块）
- **网格优化**：邻居遮挡面剔除（不生成被遮挡面的顶点数据）
